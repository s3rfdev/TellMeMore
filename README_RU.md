## Зачем нужен TellMeMore?

Собеседования — это стресс. Даже сеньоры и тимлиды под прессингом могут забыть синтаксис, растеряться на неожиданном вопросе по архитектуре или упустить детали system design. Традиционные шпаргалки на втором мониторе не спасают: движение глаз моментально выдает вас на веб-камере.

**TellMeMore** становится вашим персональным невидимым суфлёром:
1. **Слушает разговор в реальном времени:** захватывает речь вашего микрофона и голос интервьюера через независимые аудиопотоки без задержек.
2. **Ведёт живую хронологическую транскрипцию:** точно определяет реплики («Я» vs «Интервьюер»).
3. **Генерирует ответы от первого лица по горячей клавише (`⌥ 1` / `Get answer`):** учитывает ваше резюме, опыт, специфику компании и установленные цели диалога.
4. **Мгновенно решает задачи с экрана (`⌥ 2`):** делает скриншот задачи в IDE или браузере и скармливает мультимодальной LLM.
5. **100% невидимость при демонстрации экрана (`NSWindow.SharingType.none`):** даже если вы расшарите весь рабочий стол в Zoom, Google Meet, Microsoft Teams или Slack, приложение TellMeMore остаётся полностью невидимым для зрителей и записей.

## Ключевые возможности

- **Двухпоточная аудиоизоляция (100% точность разделения спикеров):**
  - Ваш голос записывается напрямую с аппаратного микрофона.
  - Голос собеседника принимается через виртуальный аудиодрайвер [BlackHole](https://existential.audio/blackhole/).
  - Оба потока отправляются одновременно в Deepgram Nova-3 по защищённому протоколу WebSocket. Никаких наводок, эха и ошибок определения говорящего.
- **Строгая хронология диалога:**
  - Каждая фраза снабжается таймстемпом и естественной разбивкой по границам предложений (`.`, `!`, `?`).
  - При быстром обмене короткими репликами контекст диалога выстраивается в идеальном порядке.
- **Полная маскировка от захвата экрана (Stealth Mode):**
  - Использование нативного флага macOS `NSWindow.SharingType.none`.
  - Окно исключается на уровне WindowServer из всех захватов экрана, демонстраций и скриншотов (Zoom, Google Meet, Teams, Slack, OBS).
- **Плавающий полупрозрачный HUD-интерфейс:**
  - Реальная попиксельная прозрачность (0–100%): читайте подсказки, глядя прямо в камеру или терминал.
  - Режимы заголовка: скрытый, полупрозрачный или сплошной.
  - Опция «Поверх всех окон» (`Always on Top`).
  - Интерактивный разделитель высоты между окном подсказки и стеком транскрипта.
  - Тонкая настройка типографики (размер шрифта 6–24px, жирность, межстрочный интервал, цветовые темы).
- **Поддержка ведущих провайдеров LLM:**
  - **Google Gemini** (Gemini 2.5 Flash, 3.8 Flash, gemini-3.5-flash-lite, Gemini Pro).
  - **Anthropic Claude** (Claude 3.7 Sonnet, Haiku, Opus).
  - **OpenAI** (GPT-4o, GPT-4o-mini, o3-mini).
  - **Z.ai / Zhipu GLM** (GLM-4.7-Flash, GLM-4.5-Flash).
  - Встроенный тест доступности API прямо в настройках.
- **Интеллектуальная работа с контекстом:**
  - Скользящее окно диалога (от 5 до 100 реплик).
  - Автоматическая компрессия: при достижении заданного объема символов (например, 3500 знаков) ранняя часть разговора компактно суммаризуется, а свежие реплики остаются дословными.
  - Профиль кандидата и цели интервью гарантированно передаются в полном объёме с каждым запросом.

## Быстрый старт (Установка)

### Вариант 1: Загрузка готового приложения (Рекомендуется)

1. Скачайте архив `TellMeMore-macOS.zip` со страницы [Releases](https://github.com/s3rfdev/TellMeMore/releases).
2. Распакуйте архив и переместите `TellMeMore.app` в папку `/Applications`.
3. Запустите приложение. Если macOS заблокирует запуск через Gatekeeper:
   ```bash
   xattr -cr /Applications/TellMeMore.app
   ```

### Вариант 2: Сборка из исходников

#### Предварительные требования
- macOS 13+ (Ventura, Sonoma, Sequoia)
- [Flutter 3.29+](https://flutter.dev) (или через [FVM](https://fvm.app))
- Xcode и Command Line Tools
- [Homebrew](https://brew.sh)

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/s3rfdev/TellMeMore.git
cd TellMeMore

# 2. Установите зависимости
flutter pub get

# 3. Соберите релизную версию
flutter build macos --release

# 4. Запустите приложение
open build/macos/Build/Products/Release/TellMeMore.app
```

## Настройка аудио (разово, занимает 2 минуты)

Чтобы перехватывать голос собеседника без эха и акустических наводок, рекомендуется использовать бесплатный драйвер **BlackHole 2ch**:

1. **Установите BlackHole**:
   ```bash
   brew install --cask blackhole-2ch
   ```
2. **Создайте многовыходное устройство (Multi-Output Device)**:
   - Откройте системное приложение **«Настройка Audio-MIDI»** (через Spotlight `Cmd + Space`).
   - Нажмите значок **`+`** в левом нижнем углу и выберите **«Создать многовыходное устройство»**.
   - Отметьте флажками **ваши наушники** И **BlackHole 2ch**.
   - Убедитесь, что наушники стоят первыми в списке (главное устройство), а на BlackHole включена «Коррекция дрейфа».
3. **Настройте звук в программе звонка (Zoom / Meet / Teams / браузер)**:
   - В настройках звука звонка выберите **Вывод (Динамики)** $\rightarrow$ созданное **Многовыходное устройство**.
   - В качестве **Ввода (Микрофона)** оставьте ваш реальный аппаратный микрофон.
4. **Настройте TellMeMore**:
   - Откройте **Настройки (⚙) $\rightarrow$ LLM $\rightarrow$ AUDIO**:
     - **Ваш микрофон:** `Системный по умолчанию` (или гарнитура).
     - **Голос собеседника:** `BlackHole 2ch`.

Теперь вы слышите собеседника в наушниках, а TellMeMore параллельно транскрибирует его речь в реальном времени!

## API-ключи

Для работы приложения требуются ключи сервиса распознавания речи (STT) и LLM:

| Сервис | Назначение | Стоимость / Бесплатный лимит | Где получить |
|---|---|---|---|
| **Deepgram** | Потоковый STT реального времени (`nova-3` / `flux`) | **\$200 бонус** при регистрации | [console.deepgram.com](https://console.deepgram.com) |
| **Google Gemini** | Генерация ответов и решение задач | Бесплатные квоты (Free tier) | [aistudio.google.com](https://aistudio.google.com) |
| **Z.ai (GLM)** | Быстрый альтернативный провайдер | Бесплатные flash-модели | [z.ai](https://z.ai) |
| **OpenAI / Claude** | Продвинутые рассуждающие модели | Оплата за токены | [platform.openai.com](https://platform.openai.com) / [console.anthropic.com](https://console.anthropic.com) |

Все ключи хранятся исключительно локально в конфигурационном файле `~/.sobes_helper.json`. Никакие данные не отправляются на сторонние серверы аналитики.

## Приватность и безопасность

- **Полное отсутствие телеметрии:** Никакого трекинга, аналитики и передачи логов.
- **Локальное хранилище:** Настройки, API-ключи и профиль хранятся локально в файле `~/.sobes_helper.json`.
- **Прямые соединения:** Аудиопоток отправляется напрямую с устройства в Deepgram по защищённому каналу WebSocket (`wss://`), а запросы к LLM идут напрямую к официальным эндпоинтам Google, Anthropic, OpenAI или Zhipu.
