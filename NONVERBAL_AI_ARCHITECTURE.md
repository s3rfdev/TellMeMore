# MIMIC — Архитектура анализа невербального поведения и микромимики

## 1. Концепция и назначение
**MIMIC** — интеллектуальный тактический HUD-ассистент и тренажёр переговоров, объединяющий:
1. Двухканальную транскрибацию речи в реальном времени (микрофон пользователя + системный звук оппонента через BlackHole).
2. Нативный анализ мимики и взгляда оппонента на базе **Apple Vision Framework** (без сторонних C++ зависимостей, нативно на Intel и Apple Silicon).
3. Детекцию ключевых микромимических реакций FACS (AU4 брови, AU24 губы, частота и блокирование морганий, увод взгляда).
4. Выделение **поведенческих кластеров** во времени (совпадение нескольких невербальных признаков в окне 0.5–2.5 с).
5. Двойной Chain-of-Thought вывод мульти-LLM (Gemini, Claude, GPT): генерация психологического профиля оппонента (`<dossier>`) и готовой реплики для произнесения (`<speech>`).

---

## 2. Иерархия уровней невербального анализа (3-уровневая воронка)

Вместо избыточного сбора 50+ абстрактных метрик (ловушка старых SDK вроде MorphCast/Affectiva), архитектура MIMIC построена на строгой 3-уровневой воронке фильтрации шума:

```
[ Уровень 0: Захват видео (Screen Crop оппонента / Веб-камера тренажёра, 5-10 FPS) ]
       │
       ▼
[ Уровень 1: Edge-фильтрация (Apple Vision / Swift) ]
       ├── VNSequenceRequestHandler & VNDetectFaceLandmarksRequest (76 2D-точек)
       ├── Eye Aspect Ratio (EAR) для обоих глаз
       ├── Pupil Gaze Offset (отклонение зрачка от центра глаза)
       ├── Lip Compression AU24 (соотношение высоты к ширине губ)
       ├── Brow Furrow AU4 (сведение бровей к переносице)
       └── Head Pose (Pitch, Yaw, Roll наклоны головы)
       │
       ▼
[ Уровень 2: Временная машина состояний (TemporalDetector / Dart) ]
       ├── Динамический нейтральный бейслайн (EMA α=0.01)
       ├── Детекция спайков (Spike duration 80-600 мс)
       ├── Анализ глазной динамики (Blink BPM, Eye Blocking >350 мс, Gaze Aversion)
       └── Агрегация кластеров:
           • CLUSTER_SUPPRESSED_STRESS (стресс морганий + поджатие губ)
           • CLUSTER_SKEPTICISM (сведение бровей + прищуривание)
           • CLUSTER_COGNITIVE_SEARCH (увод взгляда + пауза)
           • CLUSTER_FALSE_AGREEMENT (вербальное "да" + рассинхрон головы/глаз)
       │
       ▼
[ Уровень 3: Семантическая подача в LLM (PromptBuilder) ]
       ├── Привязка тегов к репликам (<turn nonverbal="...">)
       ├── Сохранение невербалики при сжатии истории диалога для RAG
       └── CoT-промптинг:
           • <dossier>: детекция манипуляций, лжи и скрытого сопротивления
           • <speech>: тактический ответ от первого лица
```

## 3. Векторный интерфейс HUD

1. **Левая колонка транскрипта (92 px):**
   * Векторные SVG-микроиконки (`NonverbalIconsBar`, 17×17 px):
     - Глазная динамика (🟢 норма, 🟡 стресс, 🔴 блокирование >350 мс);
     - Вектор взгляда (🟢 прямой контакт, 🟡 отведение);
     - Губы AU24 (🟡 сжатие);
     - Брови AU4 (🟡 сведение);
     - Алерт (🟡 / 🔴 тревожный кластер).
   * Hover-тултипы с мгновенной расшифровкой (150 мс).
2. **Основное поле транскрипта:**
   * 100% чистый текст без перегрузки оранжевыми текстовыми плашками.
3. **Верхняя панель подсказок (`HelpPanel`):**
   * Янтарная HUD-карточка с психологическим досье (`<dossier>`).
   * Текст подсказки к реплике (`<speech>`).
4. **Настройки:**
   * Опциональное скрытие микро-иконок через тумблер `showNonverbalIcons`.

## 4. Запланированные расширения (High-ROI метрики)

Перед добавлением новых метрик текущее состояние зафиксировано. Следующий этап расширения включает 2 ключевые метрики с максимальной психологической ценностью:
1. **Асимметрия лица (Facial Asymmetry):**
   - Расчёт разницы высоты уголков рта $\Delta y = |y_{\text{mouthLeft}} - y_{\text{mouthRight}}|$;
   - Разделение искренней улыбки (симметричной, подкорковой) и сарказма/ухмылки/презрения (асимметричной, корковой, AU14).
2. **Рассинхрон микродвижений головы со словами (Head Nod/Shake Leakage):**
   - Отслеживание углов `pitch` (кивок) и `yaw` (покачивание «нет»);
   - Детекция микро-покачивания «нет» при словесном утверждении «да» — ключевой маркер утечки несогласия (Leakage cue по Экману).
